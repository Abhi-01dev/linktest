# LinkTest Platform — Complete Feature Specification & User Guide

**LinkTest** is an enterprise-grade Learning Management System (LMS) and Secure Online Examination / Mock Testing Platform. It is engineered with end-to-end Role-Based Access Control (RBAC) catering to **Students**, **Teachers**, and **Administrators**, integrated with AI-driven learning tools and automated proctoring.

## 1. Core Architecture & Access Control (RBAC)

LinkTest organizes permissions across three distinct user roles with full data isolation:

| Role | Target Users | Primary Capabilities |
| :--- | :--- | :--- |
| **STUDENT** | Learners, Candidates | Enroll in courses, take mock tests under proctoring, view attendance/timetable, submit assignments, access study materials, and chat with the AI Tutor. |
| **TEACHER** | Faculty, Instructors | Manage assigned classes/batches, take daily attendance, author assignments, grade submissions, upload study materials, schedule live classes, build mock exams, and review proctoring integrity. |
| **ADMIN** | Institutional Heads, Deans | Manage users, classes, batches, subjects, and timetable; approve faculty leave; inspect audit trails; oversee exams; and configure system settings. |

## 2. Public & Authentication System

### Features:
- **Landing Page**: Modern marketing showcase featuring platform highlights, course previews, mock test highlights, statistics, and testimonials.
- **Course Catalog (`/courses`)**: Public course browsing with search, category filtering, syllabus preview, and detailed course outlines.
- **Secure Authentication**:
  - JWT (JSON Web Token) authentication stored in secure cookies and Bearer headers.
  - Password hashing with `bcryptjs`.
  - Rate limiting on login and registration to mitigate brute-force attacks.
- **Email Verification & Account Activation (`/verify-email`)**: Automated email verification tokens to confirm candidate email authenticity.
- **Password Reset Workflow (`/forgot-password`, `/reset-password`)**: Time-limited cryptographic token-based password recovery.
- **Institution Invitation Flow (`/accept-invite`)**: Tokenized enrollment invitations for students and teachers generated by administrators.

## 3. AI Tutor & Adaptive Learning

LinkTest features an integrated AI Tutor available 24/7 at `/ai-tutor` to provide interactive academic support:

- **Local & Cloud LLM Integration**: Powered by local Ollama instances (with fallback to cloud LLM APIs) for private, zero-data-leak tutoring.
- **Real-Time Streaming Responses**: Instant token-by-token answer generation for natural interaction.
- **Context-Aware Academic Guidance**: Specialized prompting tailored for Computer Science, Mathematics, Data Structures, and System Architecture.
- **Code Explanation & Syntax Highlighting**: Formats code snippets, explains algorithmic complexity (Big-O), and provides line-by-line debugging walkthroughs.
- **Interactive Practice Problems**: Generates on-demand practice questions with guided hints without revealing answers prematurely.

## 6. Examination Studio & Mock Test Engine

LinkTest provides an examination and assessment suite designed for high-stakes tests, practice mock exams, and classroom quizzes.

### 6.1 Test Authoring Studio (`/teacher/mock-tests/create`, `/teacher/mock-tests/:id/edit`)
- **Metadata Configuration**: Title, description, category, subject, topic, and difficulty (Easy, Medium, Hard).
- **Exam Rules**: Duration in minutes, total marks, pass percentage, maximum attempts, and instructions.
- **Evaluation Controls**:
  - Positive score per question.
  - Optional negative marking penalty (e.g. $-1.0$ or customizable ratio).
- **Anti-Cheat Controls**:
  - Randomize question order per candidate.
  - Randomize option choices ($A, B, C, D$) per candidate.
  - Configurable proctoring parameters (webcam, face detection, tab switch limit).
- **Flexible Question Composition**:
  - Add questions manually with options, correct answer key, and detailed solution explanations.
  - Pick questions directly from the Central Question Bank.
  - Bulk import via CSV.

### 6.2 Pre-Exam System Check (`/mock-tests/:id/check`)
- Step-by-step candidate verification wizard prior to test entry:
  1. **Webcam Verification**: Live feed check to verify camera functionality and lighting.
  2. **Microphone Check**: Audio input signal test.
  3. **Browser Fullscreen Capability**: Verifies HTML5 Fullscreen API compatibility.
  4. **System Permissions & Instructions**: Agreement to honor code and anti-cheating policies.

### 6.3 Secure Exam Runner (`/mock-tests/:id/runner/:attemptId`)
- Distraction-free, borderless examination interface (Navbar and Footer hidden).
- Real-time countdown timer with automated submission when time expires.
- **Question Palette**:
  - Status indicators: Answered (Green), Unanswered (Gray), Marked for Review (Purple), Marked & Answered.
  - Direct 1-click jump to any question number.
- **Section & Navigation**: Clear Previous / Next buttons and Clear Response options.
- **Auto-Save & State Recovery**: Candidate answers saved dynamically with resilience against accidental page reloads.

### 6.4 Comprehensive Results & Solution Analytics (`/mock-tests/attempts/:attemptId/result`)
- Overall score, percentage, percentile, and Pass/Fail status banner.
- Subject-wise and topic-wise mastery charts.
- Detailed question breakdown: compares candidate's chosen answer against the correct answer with step-by-step solution explanations.

## 7. AI & Automated Proctoring System

LinkTest incorporates continuous client-side monitoring to maintain test integrity:

### 7.1 Security & Anti-Cheat Triggers:
1. **Fullscreen Enforcement**:
   - The test runner locks into HTML5 Fullscreen.
   - Exiting fullscreen generates an instant violation strike with a warning modal.
2. **Tab-Switch & Window Blur Detection**:
   - Detects `visibilitychange` and `window.blur` events if the candidate switches tabs or minimizes the window.
   - Configurable maximum strike counter (e.g. 3 violations) which triggers automatic test submission and disqualification upon breach.
3. **Webcam Face Tracking**:
   - Continuous visual checks for:
     - **Face Absence**: Triggers alert when the candidate steps away from the camera.
     - **Multiple Faces**: Flags secondary individuals in the frame.
4. **Copy / Paste / Context Menu Lockdown**:
   - Disables text selection, right-click context menu, and keyboard shortcuts (`Ctrl+C`, `Ctrl+V`, `Ctrl+U`).

### 7.2 Integrity Score & Proctoring Audit Studio (`/teacher/mock-tests/:id/attempts/:attemptId/review`)
- Calculates a dynamic **Integrity Trust Index (0–100%)**.
- Chronological timeline log of every flagged event with timestamp, violation type, and severity.
- Teacher manual override: Ability to review, forgive false positives, or invalidate compromised attempts.

## 8. Central Question Bank & Bulk CSV Engine

Available at `/teacher/question-bank` and `/admin/question-bank`:

### 8.1 Question Repository & Filtering
- Search across question prompts, subjects, and topics.
- Filter by difficulty (Easy, Medium, Hard) and subject categories.
- Create, edit, and delete questions with full rich options and explanations.

### 8.2 Bulk CSV Import (`BulkQuestionImportModal`)
- **RFC 4180 Compliant Parser**: Supports UTF-8 with/without BOM, quotes containing commas, escaped quotes, and flexible column aliases.
- **Standard Columns**: `question`, `optionA`, `optionB`, `optionC`, `optionD`, `correctAnswer`, `subject`, `topic`, `difficulty`, `explanation`, `marks`.
- **Sample Template Download**: 1-click download of a pre-formatted `.csv` template with sample records.
- **Live Preview & Validation**:
  - Verifies answer keys ($A, B, C, D$).
  - Validates positive marks and minimum text lengths.
  - Checks for intra-file duplicates and existing database duplicates.
- **Teacher Subject Authorization Guard**:
  - Enforces that teachers can only import questions belonging to their assigned teaching subjects.
  - Admins retain unrestricted global import permissions across all subjects.
- **Error Reporting**: Generates a downloadable error report CSV detailing exact row numbers and validation failure reasons for easy fixing.

## 9. Institutional Administration & Governance

Located under the `/admin/*` control plane:

### 9.1 Admin Dashboard (`/admin`)
- High-level KPIs: Total Students, Total Faculty, Active Batches, Live Courses, Total Mock Tests Conducted, and System Health.

### 9.2 Student Roster Management (`/admin/students`)
- Add new students, generate login credentials, and assign enrollment IDs.
- Enroll students into classes and batches.
- Bulk export student lists to CSV.
- Activate, suspend, or reset student accounts.

### 9.3 Faculty Management (`/admin/teachers`)
- Onboard new teachers with employee ID, department, qualifications, and specializations.
- Assign teachers to classes, batches, and specific subjects.

### 9.4 Academic Hierarchy Configuration
- **Academic Sessions**: Configure school/university years (e.g. 2026–27).
- **Classes (`/admin/classes`)**: Define standard grade levels or cohorts (e.g. *CS Batch A*).
- **Batches (`/admin/batches`)**: Partition classes into manageable lab/lecture sections with capacity limits.
- **Subjects (`/admin/subjects`)**: Manage institution-wide course codes and curriculum titles (e.g. *CS101*, *DS101*).

### 9.5 Master Timetable Scheduler (`/admin/timetable`)
- Institution-wide master timetable builder mapping teachers, batches, subjects, days of the week, and rooms to avoid scheduling clashes.

### 9.6 Faculty Leave Approval (`/admin/leave-requests`)
- Review submitted leave applications from faculty with approval/rejection workflows and audit trails.
